# EbeeAI 文档

EbeeAI 是面向开发者和团队的 **AI API 网关与中转平台**，支持统一接入 Claude、GPT、Gemini 等主流模型。

## 核心能力

- **多模型统一接入** — 一套 API Key，路由到多个上游平台
- **用量与配额管理** — 按用户、平台维度统计与限额
- **稳定路由** — 账号池调度、故障切换与风控策略
- **管理后台** — API Key、账号、分组、计费与运维配置

## 适用场景

- 团队内部 AI 能力统一出口
- 多账号 / 多平台 API 聚合与负载均衡
- 需要用量统计、配额控制与审计的企业部署

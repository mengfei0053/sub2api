# 接入 Claude Code

Claude Code 是一个运行在终端内的 AI 编程助手。通过 EbeeAI 的 Anthropic 兼容端点，你可以使用 Claude 模型进行代码编写、重构与调试。

## 1. 安装 Claude Code

- 安装 Node.js 18+。
- Windows 用户需安装 Git for Windows。
- 在命令行执行：

```bash
npm install -g @anthropic-ai/claude-code
```

验证安装：

```bash
claude --version
```

## 2. 配置环境变量

在 [EbeeAI 控制台](https://ebeeai.net) 创建 API Key，并确认 Base URL（示例：`https://ebeeai.net/v1`）。

**macOS / Linux：**

```bash
export ANTHROPIC_BASE_URL="https://ebeeai.net/v1"
export ANTHROPIC_AUTH_TOKEN="<你的 EbeeAI API Key>"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

**Windows PowerShell：**

```powershell
$env:ANTHROPIC_BASE_URL="https://ebeeai.net/v1"
$env:ANTHROPIC_AUTH_TOKEN="<你的 EbeeAI API Key>"
$env:CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"
```

**Windows CMD：**

```cmd
set ANTHROPIC_BASE_URL=https://ebeeai.net/v1
set ANTHROPIC_AUTH_TOKEN=<你的 EbeeAI API Key>
set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

## 3. VS Code 集成（可选）

创建或编辑 `~/.claude/settings.json`（Windows：`%userprofile%\.claude\settings.json`）：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://ebeeai.net/v1",
    "ANTHROPIC_AUTH_TOKEN": "<你的 EbeeAI API Key>",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0"
  }
}
```

## 4. 开始使用

进入项目目录并启动：

```bash
cd /path/to/my-project
claude
```

## 已知问题

在 Claude Code 中，Plan Mode 可能无法自动退出。按 `Shift + Tab` 手动退出 Plan Mode，再输入内容告知 Claude Code 同意或拒绝 Plan。

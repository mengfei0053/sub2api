# 接入 Agent 工具

本文介绍如何将 **EbeeAI** 接入 Claude Code、GitHub Copilot、OpenCode、OpenClaw 等主流 AI 编程 Agent 与 CLI 工具。

## 准备工作

1. 在 [EbeeAI 控制台](https://ebeeai.net) 注册并登录。
2. 创建 API Key（以 `sk-` 开头）。
3. 在控制台 **API Key** 页面复制 **Base URL**（下文以 `https://ebeeai.net/v1` 为例）。

:::tip 端点说明
- **OpenAI 兼容**：`https://ebeeai.net/v1`（Codex、OpenCode OpenAI 模式等）
- **Anthropic 兼容**：`https://ebeeai.net/v1`（Claude Code、Copilot CLI Anthropic 模式等）
- **Gemini 兼容**：`https://ebeeai.net/v1beta`（Gemini CLI 等）
:::

## 常见问题

**401 / Authentication Fails**

检查 API Key 是否正确，且 Key 已绑定可用分组（Claude / OpenAI / Gemini 等）。

**模型不可用 / 404**

确认控制台分组平台与所选模型匹配；模型名称需与 EbeeAI 路由配置一致。

**Claude Code Plan Mode 无法自动退出**

按 `Shift + Tab` 手动退出 Plan Mode，再输入内容告知 Claude Code 同意或拒绝 Plan。
